- QR Code 不含姓名、電話、Email 或付款資料；資料庫僅保存票券雜湊。
- 新增資料表不開放 Supabase 公開角色直接讀寫。
- 瀏覽器冒煙測試發現 `academy_app` 為 `NOINHERIT` 群組，已追加 migration，直接授權實際低權限登入角色及專用 RLS policy；未改成高權限連線。
- 後台路由與報到 API 在伺服器端重新檢查角色與活動指派。
- 未將資料庫連線、SMTP 密碼、API Key、管理員邀請權杖等敏感資訊寫入版本控制。
